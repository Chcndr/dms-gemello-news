🔧 Setup Gmail Webhook Automatico

⚠️ IMPORTANTE

Questo setup è necessario per automatizzare completamente il sistema di sicurezza email.

📋 STEP 1: Webhook Endpoint

L'endpoint webhook è già creato e pronto:

https://chcndr.github.io/dms-gemello-news/landing/api/email-webhook.js

Secret webhook: dms-webhook-secret-2025

🔑 STEP 2: GitHub Token

Crea un GitHub Personal Access Token:

  1. Vai su: GitHub Settings → Tokens
  2. Clicca "Generate new token (classic)"
  3. Nome: DMS Webhook Automation
  4. Scopes: repo e workflow
  5. Copia il token generato

📧 STEP 3: Gmail API Setup

Configura Gmail per inviare webhook:

  1. Vai su: Google Cloud Console
  2. Crea nuovo progetto: "DMS Email Automation"
  3. Abilita Gmail API
  4. Crea credenziali OAuth 2.0
  5. Configura webhook URL sopra

🔄 STEP 4: Alternative Semplici

Se Gmail API è troppo complesso, usa questi servizi:

OPZIONE A - Zapier (Consigliato)

  1. Crea account su Zapier
  2. Trigger: "Gmail - New Email Matching Search"
  3. Search: from:bebaviola@gmail.com subject:"Re:"
  4. Action: "Webhooks - POST"
  5. URL: L'endpoint sopra
  6. Headers: x-webhook-secret: dms-webhook-secret-2025

OPZIONE B - IFTTT

  1. Crea account su IFTTT
  2. If: "Gmail - New email in inbox from"
  3. Email: bebaviola@gmail.com
  4. Then: "Webhooks - Make a web request"
  5. URL: L'endpoint sopra

🧪 STEP 5: Test del Sistema

Per testare manualmente il webhook:

curl -X POST https://chcndr.github.io/dms-gemello-news/landing/api/email-webhook.js \ -H "Content-Type: application/json" \ -H "x-webhook-secret: dms-webhook-secret-2025" \ -d '{"from":"bebaviola@gmail.com","subject":"Re: Accesso DMS","body":"token: test-token-123"}'
